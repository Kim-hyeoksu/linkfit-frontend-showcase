## 분리한 책임

화면은 모듈을 언제 표시할지 결정하고 데이터만 전달합니다. 차트는 데이터 날짜 정렬, Chart.js 데이터셋과 축, 플러그인 등록을 담당합니다. `hammerjs`와 줌 플러그인은 브라우저 환경에서만 등록합니다.

원본 화면의 `next/dynamic`과 직접 모듈 경로 import를 유지합니다. 공통 barrel import로 관련 없는 차트·히트맵을 함께 연결하지 않도록 경계를 명확히 합니다. `ssr: false`는 브라우저 의존성을 서버에서 실행하지 않기 위한 선택입니다.

## 공개용 변경

원본 운동 기록 상세 페이지는 운영 이미지 주소·다른 편집 기능이 포함돼 통째로 공개하지 않았습니다. 차트 모듈과 로딩 설정을 가져오고 가상 기록·표시 버튼을 추가했습니다. Tailwind에 의존하던 캔버스 높이만 인라인 스타일로 바꿔 이 저장소에서 독립 표시할 수 있도록 했습니다.

## 검증할 수 있는 것과 없는 것

빌드는 브라우저 전용 import가 서버 렌더링을 깨뜨리지 않는지 확인합니다. 실제 줌·팬은 브라우저에서 확인합니다. SSR HTTP 테스트는 차트 인터랙션을 검증하지 않습니다.

동적 import의 존재만으로 초기 번들 감소율을 단정하지 않습니다. 기존 화면과 이 공개 화면의 번들 크기를 직접 비교하는 것도 동일 조건 비교가 아닙니다. 운영 성능 주장을 하려면 동일 기능·환경에서 별도로 측정해야 합니다.
